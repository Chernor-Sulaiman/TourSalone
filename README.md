
# TourSalone – Discover, Explore, Experience Sierra Leone

## Project Overview

TourSalone is a tourism website I developed to promote the beautiful tourist attractions of Sierra Leone.

The main purpose of this website is to help local and international visitors discover interesting places, learn about tourist destinations, and explore the natural beauty, history, and culture of Sierra Leone.

I developed TourSalone as part of my Web Design assignment at Limkokwing University of Creative Technology.

## Project Objectives

The objectives of TourSalone are to:

- Promote tourism in Sierra Leone.
- Help visitors discover popular tourist destinations.
- Provide information about beaches, wildlife, historical sites, and other attractions.
- Create a simple and user-friendly tourism website.
- Develop a responsive website that works on mobile phones, tablets, and computers.
- Improve my practical skills in HTML and CSS.

## Technologies Used

The website was developed using:

- HTML5 – For creating the structure and content of the website.
- CSS3 – For styling, layouts, colours, and responsive design.
- CSS Grid – For arranging destination and service cards.
- Flexbox – For organizing navigation and other page elements.
- Media Queries – For adjusting layouts to different screen sizes.
- Visual Studio Code – For writing and editing the code.
- Git and GitHub – For version control and storing the project online.

## Website Pages

### 1. Home Page
The homepage introduces TourSalone and welcomes visitors to explore Sierra Leone. It includes tourism categories and featured destinations.

### 2. Explore Page
The Explore page displays different tourist destinations using images, descriptions, and destination cards. It includes category and location filters using CSS.

### 3. About Page
The About page explains the purpose of TourSalone and why promoting Sierra Leone's tourism attractions is important.

### 4. Services Page
The Services page presents tourism-related services and information in a clear card layout.

### 5. Contact Page
The Contact page provides contact information and a message form for visitors who want to make inquiries. The form requires FormSubmit configuration before it can receive messages.

## How to Run the Website

1. Download or clone the project from GitHub.
2. Open the TourSalone folder in Visual Studio Code.
3. Locate the index.html file.
4. Open index.html in a web browser or use the Live Server extension.
5. Navigate through the website using the navigation menu.

No database or JavaScript setup is required.

## Responsive Design

TourSalone was designed to work on different screen sizes.

CSS Grid, Flexbox, and media queries were used to adjust the layouts for desktop computers, tablets, and mobile phones.

## Current Limitations

TourSalone is currently a static website developed using HTML and CSS.

It does not include a database, user registration, or an online booking system.
